# Git Plus — Training Site

MLOps course site for Git Plus learners: GitHub → repo layout → MLflow → GCP → retraining loop → FastAPI → React. Nine modules including week-by-week timeline and demo checklists.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy the `dist/` folder to Netlify or any static host (`netlify.toml` includes SPA redirects).
